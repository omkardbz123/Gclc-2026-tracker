One-time setup

Connects this page to the GitHub repo so uploads can be published. Do this once (and again when the token expires).

Create a GitHub token:
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → pick .
  3. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  4. Generate, copy the token, paste it below.
The token is encrypted with the admin password before it is saved, and is never stored in plain text.
